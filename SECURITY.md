# Security policy

## Reporting a vulnerability

Email **security@accessible.so**. Please don't open a public issue or pull request for a
vulnerability.

Include the package and version, steps to reproduce, and the impact you see. We'll confirm we
received it, keep you updated while we fix it, and credit you in the release notes if you'd like.

## Supported versions

Security fixes go into the latest release of each package: `@accessible-so/monitor`,
`@accessible-so/monitor-core`, `@accessible-so/monitor-next` and `@accessible-so/monitor-astro`.

## Scope

This repository's packages and the SWC plugin. Issues in the Accessible service
(`accessible.so`, `app.accessible.so`) go to the same address.
